## អំពីប្លុកនេះ។

**នៅទីនេះ ស្វែងយល់ពីប្រទេសចិន** គឺជាប្លុកស៊ីជម្រៅពហុភាសាសម្រាប់អ្នកអានទូទាំងពិភពលោក។

នៅក្នុងយុគសម័យដែលព័ត៌មានត្រូវបានបែងចែកយ៉ាងខ្លាំង ការនិទានរឿងធំៗ និងគំរូត្រូវបានជាប់ទាក់ទងគ្នា យើងព្យាយាមហួសពីពាក្យស្លោក និងតម្រង ហើយត្រឡប់ទៅបរិបទប្រវត្តិសាស្ត្រដ៏វែងរបស់ប្រទេសចិន ការពិតសង្គមដ៏រស់រវើក និងបទពិសោធន៍ជីវិតពិតរបស់មនុស្សសាមញ្ញ ដើម្បីបង្ហាញពីប្រទេសចិនបីវិមាត្រ ជាក់ស្តែង យល់ឃើញ និងអាចស្គាល់បាន។

នៅទីនេះយើងរុករក៖

- **ប្រវត្តិសាស្ត្រ និងការចងចាំ**៖ ការយល់ដឹងពីមូលដ្ឋាននៃការគិតរបស់ប្រទេសចិនសហសម័យគឺមិនអាចបំបែកចេញពីការពិនិត្យឡើងវិញនៃរបួស ការផ្លាស់ប្តូរ និងការរុករកប្រវត្តិសាស្រ្តទំនើប និងបុរាណរបស់វា។
- **ការពិត និងអភិបាលកិច្ច**៖ ពីអាហារនៃជីវិតប្រចាំថ្ងៃ ព័ត៌មានលម្អិតនៃប្រតិបត្តិការទីក្រុង ដល់តក្កវិជ្ជានៃអភិបាលកិច្ចមូលដ្ឋាន សង្កេតមើលពីរបៀបដែលសង្គមដំណើរការជាមួយមនុស្ស 1.4 ពាន់លាននាក់។
- **វប្បធម៌ និងទស្សនវិស័យ**៖ បំបែកចេញពីពាក្យស្លោកមនោគមវិជ្ជាស-ខ្មៅ ហើយកត់ត្រានូវអ្វីដែលប្រជាជនចិនគិត មានអារម្មណ៍ និងចង់បានជាពាក្យសាមញ្ញ និងសមហេតុផល។
