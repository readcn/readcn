## هن بلاگ جي باري ۾

**هتي، چين کي سمجھو** عالمي پڙهندڙن لاءِ هڪ گهڻ-ٻوليءَ ۾ گهرو بلاگ آهي.

هڪ اهڙي دور ۾ جتي معلومات انتهائي ورهايل آهي، وڏيون روايتون ۽ اسٽريٽائپس هڪ ٻئي سان جڙيل آهن، اسان نعرن ۽ فلٽرن کان اڳتي وڌڻ جي ڪوشش ڪريون ٿا ۽ چين جي ڊگهي تاريخي حوالي سان، وشد سماجي حقيقتن ۽ عام ماڻهن جي حقيقي زندگي جي تجربن ڏانهن موٽڻ جي ڪوشش ڪريون ٿا، هڪ ٽي طرفي، ٺوس، سمجهڻ ۽ ڄاڻڻ وارو چين پيش ڪرڻ لاء.

هتي اسين ڳوليون ٿا:

- **تاريخ ۽ يادگيري**: معاصر چين جي بنيادي سوچ کي سمجهڻ ان جي جديد ۽ قديم تاريخي صدمن، تبديلين ۽ ڳولان جي جائزي کان الڳ نه آهي.
- **حقيقت ۽ گورننس**: روزاني زندگيءَ جي کاڌن کان وٺي، شهري آپريشن جا تفصيل گراس روٽ گورننس جي منطق تائين، ڏسو ته ڪيئن سماج 1.4 بلين ماڻهن سان هلندي آهي.
- **ثقافت ۽ نقطه نظر**: ڪارو ۽ اڇي نظرياتي نعرن کان پري ٿيو ۽ رڪارڊ ڪيو ته چيني ماڻهو ڇا سوچين ٿا، محسوس ڪن ٿا ۽ چاهين ٿا صاف ۽ معقول لفظن ۾.
