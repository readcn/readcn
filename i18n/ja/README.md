## このブログについて

**ここで中国を理解してください** は、世界中の読者を対象とした多言語の詳細なブログです。

情報が高度に断片化され、壮大な物語と固定観念が絡み合う時代において、私たちはスローガンやフィルターを超えて、中国の長い歴史的背景、生き生きとした社会現実、庶民の実生活体験に立ち返り、三次元的で具体的、知覚でき、知ることができる中国を提示しようと努めています。

ここでは次のことを調べます。

- **歴史と記憶**: 現代中国の根底にある考え方を理解するには、現代および古代の歴史的トラウマ、変化、探求を振り返ることが不可欠です。
- **現実とガバナンス**: 日常生活の食事、都市運営の詳細から草の根のガバナンスの論理に至るまで、14 億人が暮らす社会がどのように運営されているかを観察してください。
- **文化と視点**: 白か黒かのイデオロギー的なスローガンから脱却し、中国人が考え、感じ、望んでいることを平易かつ合理的な言葉で記録します。

## 多言語とサブスクリプションのサポート

- **75 言語のバリアフリー読書**: サイト全体のインターフェースとすべての記事が **75 言語**に対応しており、自由に切り替えることができます。どの国や地域から来たとしても、母国語で読むことができます。
- **多言語全文 RSS 購読**: 各言語で独立した全文 RSS 2.0 フィードが提供され (Web サイトの右上隅で言語を切り替え、RSS アイコンをクリックすると、対応する言語の購読アドレスを取得できます)、すべての主流の RSS リーダーが記事全体を直接読むことができます。
- **オープンなコミュニケーション**: [コミュニティ フォーラム](https://github.com/orgs/readcn/discussions) へようこそ。意見を共有したり、質問したり、多言語ディスカッションに参加したりできます。
