## 關於這篇部落格

**在這裡，讀懂中國** 是一個面向全球讀者的多語言深度部落格。

在資訊高度碎片化、宏大敘事與刻板印象交織的時代，我們試圖跨越口號與濾鏡，回到中國漫長的歷史脈絡、鮮活的社會現實與普通人的真實生活經驗之中，呈現一個立體、具體、可感可知的中國。

在這裡，我們探討：

- **歷史與記憶**：理解當代中國的思維底色，離不開對其近代與古代歷史創傷、變革與探索的回望。
- **現實與治理**：從日常生活的一餐一飯、城市運作的細節到基層治理的邏輯，觀察十四億人社會如何運作。
- **文化與觀點**：跳脫非黑即白的意識形態口號，以平實、理性的文字記錄中國人的所思、所感與所求。

## 多語言與訂閱支持

- **75 種語言無障礙閱讀**：全站介面與所有文章均支援 **75 種語言**自由切換，無論您來自哪個國家或地區，都能以母語閱讀。
- **多語言全文 RSS 訂閱**：每個語種均提供獨立的全文 RSS 2.0 訂閱源（在網站右上角切換語言後點擊 RSS 圖標即可獲取對應語種的訂閱地址），支援所有主流 RSS 閱讀器直接閱讀完整文章。
- **開放交流**：歡迎前往 [社區論壇](https://github.com/orgs/readcn/discussions) 分享您的思考、提問或參與多語言討論。
