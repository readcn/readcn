## 关于本博客

**在这里，读懂中国** 是一个面向全球读者的多语言深度博客。

在信息高度碎片化、宏大叙事与刻板印象交织的时代，我们试图跨过口号与滤镜，回到中国漫长的历史脉络、鲜活的社会现实与普通人的真实生活经验之中，呈现一个立体、具体、可感可知的中国。

在这里，我们探讨：

- **历史与记忆**：理解当代中国的思维底色，离不开对其近代与古代历史创伤、变革与探索的回望。
- **现实与治理**：从日常生活的一餐一饭、城市运转的细节到基层治理的逻辑，观察十四亿人社会如何运作。
- **文化与视角**：跳出非黑即白的意识形态口号，以平实、理性的文字记录中国人的所思、所感与所求。
